#### B. Flawed Metric Aggregations & Fallbacks (Lines 24–49)
```tsx
// Calculate dynamic aggregated metrics from graph data
const { totalTradeVolume, avgSupplyRisk, connectedPartners } = useMemo(() => {
  if (!graph || !graph.nodes.length) {

  let totalRisk = 0;
  let riskCount = 0;

  graph.edges.forEach(e => {
    const vol = Number(e.properties.tradeVolume) || Number(e.properties.weight) || 0;
    totalVol += vol;
  });

  graph.nodes.forEach(n => {

      totalRisk += n.properties.risk;
      riskCount += 1;
    }
  });

  // If tradeVolume was stored in billions, display in Trillions or Billions
  const formattedVol = totalVol > 1000 ? `$${(totalVol / 1000).toFixed(1)}T` : totalVol > 0 ? `$${totalVol.toFixed(1)}B` : '$14.2T (Est)';
  const formattedRisk = riskCount > 0 ? `${Math.round((totalRisk / riskCount) * 100)}%` : '28%';
  ...
```
**Critical Issues Discovered:**
1. **Deceptive Hardcoded Fallbacks:** If `totalVol === 0`, it displays `'$14.2T (Est)'`. If `riskCount === 0`, it displays `'28%'`. This masks empty or failed datasets by showing fictitious economic figures.
2. **Arbitrary Unit Scaling:** Synthetic data generated by `seed_neo4j_trade.py` generates volumes between `10,000` and `500,000`. Summing 178 edges yields ~`45,000,000`. Dividing by 1,000 yields `$45000.0T` ($45 Quadrillion). There is no currency definition or unit normalization.

#### C. Top Influencer ID Mismatch Bug (Lines 72–89, Line 309)
```tsx
const topInfluencers = useMemo(() => {
```

And in line 309:
```tsx
onClick={() => {
  const matched = graph?.nodes.find(n => n.id === country.id);
  if (matched) setSelectedNode(matched);

```
**Root Cause of Complete Selection Failure:**
- The backend centrality endpoint returns:
  `n.iso3 AS node_id` (e.g., `"USA"`, `"CHN"`).
- The backend network endpoint returns:
  `node_id = str(value.element_id)` (e.g., `"4:624f21a6-4ee2-4cee-8117-d08e852d7577:18"`).
- Therefore, `graph?.nodes.find(n => n.id === "USA")` evaluates to `undefined` every single time!
- Clicking on ANY country in the top influencers list does nothing.

### 2.2 Network Visualizer Component (`TradeGraph.tsx`)
**File Path:** `apps/web/src/components/charts/TradeGraph.tsx` (204 lines)  
**Dependencies:** `react-cytoscapejs`, `cytoscape`, `next-themes`  

#### A. Inverted Boolean Logic Bug in Edge Dimming (Line 47)
```tsx
const cyEdges = edges.map(edge => {
  const edgeDimmed = !hasActiveFilter || (!visibleNodeIds.has(edge.source) && !visibleNodeIds.has(edge.target));
  return {
    data: { 
      ...edge.properties,
      id: edge.id, 
      source: edge.source, 
      target: edge.target,
      label: edge.type,
      dimmed: edgeDimmed ? 'true' : 'false'
    }
  };
});
```
And in stylesheet (lines 143–147):
```tsx
{
  selector: 'edge[dimmed = "true"]',
  style: {
    'opacity': 0.1,
  }
}
```
**Bug Explanation:**
- When the dashboard first loads, `hasActiveFilter` is `false`.
- Therefore, `!hasActiveFilter` evaluates to `true`!
- Consequently, `edgeDimmed` is `true` for **all 189 edges** in the graph by default.
- Every edge is rendered at `opacity: 0.1` (virtually invisible faint lines).
- When a user types a filter query, `hasActiveFilter` becomes `true`, making `!hasActiveFilter` `false`, which unexpectedly causes matching edges to become *brighter* (`opacity: 0.6`).
- This inverted logic destroys the initial visual presentation of the network.

#### B. Hardcoded Edge Thickness (Lines 111–126)
```tsx
selector: 'edge',
style: {
  'width': 2,
  'line-color': isDark ? '#4b5563' : '#9ca3af',
  ...
}
```
**Finding:**
- Requirement E specifies edge thickness based on trade volume.
- In `TradeGraph.tsx`, edge width is hardcoded to `2`.
- No Cytoscape functional mapper (e.g., `mapData(tradeVolume, ...)`) is implemented.

#### C. Layout Instability & UI Freezing Risk (Lines 173–179)
```tsx
layout={{ 
  name: 'cose',
  animate: false,
  randomize: true,
  nodeRepulsion: 400000,
  idealEdgeLength: 100
}}
```
**Finding:**
- The Cytoscape `cose` layout algorithm runs on the main JavaScript thread.
- Setting `randomize: true` causes the entire graph layout to reshuffle into random coordinates whenever React re-renders `CytoscapeComponent` (such as when typing in the search box).
- On larger networks (>100 nodes, >1,000 edges), `cose` execution will block the event loop, freezing user interactions.

### 2.3 API Integration Hook (`useGraph.ts`)
**File Path:** `apps/web/src/hooks/useGraph.ts` (73 lines)  

```tsx
export function useGlobalNetwork() {
  return useQuery({
    queryKey: ['graph', 'network'],
    queryFn: async () => {
      const response = await apiClient.get<GraphResponse>('/graph/network');
      return response.data;
    },
    staleTime: 5 * 60 * 1000,
  });
}

export function useCentrality() {
  return useQuery({
    queryKey: ['graph', 'centrality'],
    queryFn: async () => {
      const response = await apiClient.get<CentralityRank[]>('/graph/centrality');
      return response.data;
    },
    staleTime: 5 * 60 * 1000,
  });
}
```
**Finding:**
- Clean TanStack React Query implementation with appropriate 5-minute cache stale time.
- However, it does not support passing query parameters (such as `year`, `region`, or `commodity_id`).
- It completely ignores backend endpoints `/api/v1/graph/neighbors/{node_id}` and `/api/v1/graph/path`.
