## 1. Data Classification Framework

Every data artifact, endpoint output, and variable related to the Trade Network module is classified into one of the seven mandated tiers:

1. **VERIFIED REAL DATA** (Direct empirical observations from authentic statistical agencies with established provenance).
2. **REAL DATA SOURCE, BUT NOT VERIFIED** (Authentic APIs referenced, but responses are unverified, cached without headers, or incomplete).
3. **HISTORICAL SNAPSHOT** (Static capture of real empirical data at a specific past point in time).
4. **SYNTHETIC / MOCK** (Procedurally generated, simulated, or randomized values).
5. **HARDCODED STATIC DATA** (Hardcoded values embedded directly into source code).
6. **FALLBACK DATA** (Default values returned when primary retrieval fails).
7. **UNKNOWN PROVENANCE** (Data whose origin cannot be reliably traced).

### 3.2 Ingestion Script: `download_trade.py`
- **Location:** `apps/api/ml/scripts/download/download_trade.py`
- **API Endpoint:** `https://comtradeapi.un.org/public/v1/preview/C/A/HS`
- **Configuration Defaults:**
  - `reporter`: `"842"` (USA)
  - `partner`: `"0"` (World Aggregate)
  - `commodity`: `"TOTAL"`
  - `output_dir`: `DEFAULT_RAW_DIR = Path(__file__).resolve().parent.parent.parent / "datasets" / "raw"`
- **Critical Findings:**
  1. The target path `apps/api/ml/datasets/raw` does not exist in the repository.
  2. The script queries single reporter/partner pairs sequentially without rate-limiting backoff (UN Comtrade free preview API limits queries to 500 requests per day and 1 request per second).
  3. The script was never wired into the data transformation pipeline. Not a single raw JSON file from this script exists in `data/raw/` or `data/processed/`.

### 3.3 Silent Fallback Mechanisms

#### Frontend Silent Fallback (`TradeNetworkPage.tsx`)
```tsx
const formattedVol = totalVol > 1000 ? `$${(totalVol / 1000).toFixed(1)}T` : totalVol > 0 ? `$${totalVol.toFixed(1)}B` : '$14.2T (Est)';
const formattedRisk = riskCount > 0 ? `${Math.round((totalRisk / riskCount) * 100)}%` : '28%';
```
- **User Impact:** When Neo4j fails to return nodes/edges or an empty graph is returned, the dashboard continues to display `Total Trade Volume: $14.2T (Est)` and `Avg Supply Risk: 28%`. Users are misled into believing live real-world aggregates are being computed.

#### AI Feature Extractor Silent Fallback (`graph_metrics.py`)
```python
except Exception as e:
    logger.debug(f"Neo4j topology query unavailable for {iso3}, using baseline graph features: {e}")
return default_features
```
- **Impact on ML Pipeline:** If the database is offline or properties are missing, constant numbers (`0.045`, `0.12`, `0.28`, `42.0`, `38.0`) are silently fed into the models, eliminating any signal of network interconnectedness during inference.
