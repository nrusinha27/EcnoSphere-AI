### Speaking Script:
> "Now let us examine Stage 2: Interactive GDP Forecasting.
>
> Here we interface directly with our frozen Phase 11 production machine learning model—a HistGradientBoostingRegressor trained on longitudinal macroeconomic panel data with a verified test RMSE of 3.91 percentage points.
>
> Crucial academic governance distinctions to highlight:
>
> - **1. Empirical Prediction Interval vs. Confidence Band:** Notice the uncertainty interval $[\hat{y} - 11.45, \hat{y} + 11.45\text{ pp}]$. This is derived from the 90th percentile of absolute out-of-sample validation residuals ($Q_{90} = 11.4507$). We strictly term this an *Empirical Prediction Interval*, avoiding the statistically invalid claim of a Gaussian confidence band.
> - **2. Model Prediction Shift vs. Causal Impact:** In the results panel, notice the label: **Model Prediction Shift (Delta)** with the explicit subtitle: *'Relative to baseline model projection (non-causal)'*. This is a critical distinction: supervised regression models calculate statistical correlation shifts based on historical feature associations; they do not establish structural econometric causality.
> - **3. Background Feature Imputation:** Out of 31 model features, we allow user experimentation on 11 primary economic indicators. The remaining 20 derived, lag, and contextual features are held constant or imputed using frozen training-cohort medians, which are fully disclosed in the expandable input feature table."

>
> - When we launch a scenario, FastAPI writes a simulation record to PostgreSQL in `PENDING` state and enqueues a background job to Redis.

## 5. Fallback Procedures & Fault Tolerance (2 Minutes)

### Speaking Script:
> "In real-world deployment, microservices occasionally degrade. We engineered EconoSphere AI with comprehensive fault tolerance:
>
> 1. **What if the Neo4j Graph Database is offline?** The application does not crash. The trade dependency engine automatically falls back to cached bilateral trade graphs, as verified by our regression tests.
> 2. **What if Redis or the background worker is stopped?** Country Comparison and GDP Forecasting are separate application modules that operate synchronously in-process without Redis. Crisis Simulation depends on the Redis queue and a running simulation worker; if either service is unavailable, simulation submission or background processing will fail while the synchronous comparison and forecasting modules remain accessible.
> 3. **What if an unsupported country is requested for forecasting?** The model returns an HTTP 404 with a helpful message explaining that the Phase 11 model is calibrated exclusively for 5 core benchmark economies (`CHN, GBR, IND, JPN, USA`)."
